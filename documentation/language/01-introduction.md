# 1. Introduction to XCX

## 1.1. What is XCX

XCX is an experimental, general-purpose programming language designed around:

- Explicitness and code readability
- Static typing and safety
- Minimization of default assumptions

The guiding principle: **"Better clear code than fast code."**

## 1.2. Characteristics and Applications

XCX is:

- General purpose with a backend tendency
- Statically typed with rigorous validation
- Focused on safety and reliability
- Team-friendly

Typical use cases:

- Backend systems and APIs
- Business applications
- Analytical tools
- System prototyping
